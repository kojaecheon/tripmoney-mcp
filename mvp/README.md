## 3분 체험 순서

1. 운영자: 공항 택시 금액을 `450`에서 `500`으로 변경하고 재계산한다. 합계는 547,052원에서 548,982원으로 바뀐다. 결제자와 분담 대상도 변경할 수 있다.
2. 운영자: `현재 버전 검수 확인`을 누른다. 실제 영수증 검수가 아니라 샘플 합계 확인이다.
3. 총무: 멤버별 낸 금액·부담액·송금 제안을 확인하고 `이 버전 승인`을 누른다.
4. 참여자: 본인 결과를 확인하고 고정 사유로 이의를 제기한다. 총무 화면에서 이의 건수와 마감 차단을 확인한다.
5. 참여자: 이의를 철회한다. 철회는 승인이 아니므로 승인 여부를 별도로 선택한다.
6. 총무: `검토창 종료 시연`, `현재 버전 잠금`을 누른다. 무응답은 그대로 남으며 잠금 후에는 지출과 응답을 변경할 수 없다.
7. 복원: 새로고침해도 샘플 상태가 남는다. `샘플 초기화`에서 확인하면 최초 데이터로 돌아간다.

## 체험 데이터와 저장

- 집계 대상: 합성 멤버 5명과 지출 12건. 제목·통화·환율은 고정이다. 원화 환산 후 1원 단위로 분담하며 잔여 1원은 고정 멤버 순서대로 배분한다.
- 버전: 지출 내용이 실제로 변경되면 버전이 증가한다. 총무 승인, 참여자 응답, 내부 검수, 검토 종료 상태는 초기화된다.
- 다중 탭: 작성 중 지출 입력은 다른 탭의 응답 변경으로 지워지지 않는다. 다른 탭에서 지출 버전이 바뀌면 이전 초안 저장은 거부한다. 지출 목록에서 해당 항목을 다시 선택해 최신 상태를 확인한다.
- 저장 위치: 현재 브라우저의 `tripmoney.experience.v1` 키. 초기화는 이 키만 변경한다.
- 저장 실패: 화면 상단에 메모리 모드가 표시된다. 이때 새로고침하면 변경 내용이 사라진다.
- 저장 손상: 형식이 다르거나 합성 샘플 범위를 벗어나면 최초 상태로 복구하고 안내한다.
- 체험 링크: 같은 브라우저와 같은 접속 주소에서 참여자 화면을 여는 용도다. 다른 브라우저나 컴퓨터로 상태를 전달하지 않는다. 클립보드가 지원되지 않으면 직접 복사할 수 있는 창을 제공한다.
- 역할 전환: 로그인이나 접근권한 검증이 아니다. 참여자 화면은 본인 관련 결과만 표시하지만 전체 합성 상태는 브라우저에 있다.

## 1차 범위 제외

실제 여행·고객 등록, 연락처·계좌 입력, 직원 로그인, 실사용자 권한 분리, 영수증 업로드·OCR, 실시간 환율, DB 저장, 외부 링크 권한·만료, 결제·송금·환불, 이메일·카카오 발송, 운영 배포는 제공하지 않는다.

기존 `api/`, `lib/`, `public/` 서버는 이 MVP가 수정하거나 보호하지 않는다. 실제 고객 데이터 접수 전에는 별도 신뢰 기반 작업과 출시 검증이 필요하다.

