| `git diff --check` | 오류 없음 | 변경 파일 공백 검사 |

검증 런타임: 로컬 Node `v25.6.1`. Node 22에서의 별도 재현은 이번 검증에 포함하지 않았다. 새 MVP는 Node 기본 모듈만 사용하고 신규 npm 의존성을 추가하지 않았다. 기존 서비스의 알려진 의존성 취약점을 해결한 것으로 표시하지 않는다.

테스트 절차: 먼저 기능 누락 또는 회귀 실패를 확인한 후 구현·수정했다. 모바일 CSS 검사는 구조 규칙 검사와 실제 브라우저 너비 검사를 함께 사용했다. 앱 이벤트 테스트는 최소 DOM 스텁이며 실제 두 탭 시연과 구분한다.

## 5. 독립 검토와 수정

Codex 별도 검토자는 읽기 전용으로 MVP 코드와 테스트를 확인했다. 수정 후 재검토 결과 잔여 Critical·Important 지적사항은 없으며 테스트 24개 통과를 별도로 확인했다.

| 구분 | 지적 또는 발견 | 처리 |
|---|---|---|
| Important, Codex 검토 | storage 이벤트가 작성 중 지출 입력을 덮음 | 초안 보존, 이전 버전 저장 거부, 재선택 갱신. 테스트와 실제 두 탭으로 재검증 |
| Minor, Codex 검토 | 저장된 분담 배열 순서가 잔여 1원 배분을 바꿈 | 계산 시 고정 멤버 순서 적용. 역순 배열 회귀 테스트 통과 |
| 화면 검증 | 모바일 표의 최소 너비가 카드 전체를 밀어냄 | grid 자식 축소 허용, 표 내부 스크롤. 375px에서 scrollWidth 375 확인 |
| 화면 검증 | 큰 금액이 옆 집계 항목을 덮음 | 좁은 화면 단일 열 집계. 1,000,000 THB 입력으로 확인 |
| 화면 검증 | 무변경 저장 안내가 재승인을 요구함 | 변경 없음·기존 승인 유지 문구로 분기. 이벤트 테스트와 브라우저 재검증 |

Claude 초기 검토 시도: 제공한 MVP 소스와 테스트만 입력으로 전달했고 도구·MCP를 비활성화한 읽기 전용 검토를 요청했다. CLI가 `401 OAuth access token has expired`를 반환해 당시 검토 결과는 생성되지 않았다. 사용자 재로그인 후 실제 검토와 후속 재검토를 완료했다. 처리 내역은 8절에 기록한다. Codex 검토를 Claude 검토로 대체 표기하지 않는다.

## 6. 후속 개발의 경계

- 구현 완료: 승인된 합성 데이터 체험 흐름, 로컬 실행, 사용 안내, 자동 회귀, 브라우저 확인, Codex·Claude 독립 검토와 후속 수정.
- 남은 선택: GitHub 반영 방식. 추가 로그인이나 기능 개발은 이번 MVP 인계의 필수 작업이 아니다.
- 1차 범위 제외: 고객 등록·연락처·계좌, 직원 인증, 실제 권한, 영수증 업로드·OCR, DB, 외부 공유, 결제·송금·환불, 운영 배포.
- 기존 시스템: 공개 베타 API, 레거시 DB 연결, 의존성 취약점 등은 이 MVP가 변경하지 않았다. 운영 차단 완료로 주장하지 않는다.
- Git: 이번 결과를 로컬 작업 브랜치에 보존한다. GitHub push·PR·merge·배포는 이번 승인 범위에서 실행하지 않는다.

적용 절차: `using-superpowers`, 테스트 우선 개발, UI 스킬 라우팅과 Rams 체크리스트, 원인 확인 디버깅, 독립 코드 검토, 완료 전 증거 확인을 적용했다. 기존 목업의 색·서체·카드 기준을 재사용하고 실사용자 개발을 추가하지 않았다.
