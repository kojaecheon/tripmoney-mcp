## 4. 00A-2에 전달할 확정 계약

파일 범위:

- 생성: `supabase/migrations/0008_internal_staff_auth_real_data_boundary.sql`
- 수정: `lib/db.ts`, `lib/server.ts`, `lib/mcpEngine.ts`, `lib/guards.ts`, `lib/audit.ts`, `api/web.ts`
- 검증: 전체 `supabase/migrations/*.sql`, 역할 DSN 직접 연결과 합성 데이터 부정 테스트
- 운영 기록: 데모 초기화, 자격정보 회전, 최소권한 전환의 승인된 런북

DB 계약:

- 기존 0001~0007은 수정하지 않는다. 0008은 적용 전에 staff/session 조회·폐기 함수까지 한 번에 검토한다.
- `trips`, `beta_leads`의 `data_class`는 `quarantined|demo|real`, NOT NULL, default 없음. 기존 행은 quarantined, 런타임 재분류 금지.
- real 여행의 `api_key`, `share_token`, 계좌 값은 NULL. child 관계의 부모 분류와 동일 여행 참조를 DB에서 강제한다.
- `tm_admin_app`, `tm_reviewer_app`, `tm_auth_app`, `tm_lead_app`, `tm_privacy_job`, `tm_demo_app`, `tm_migration`은 별도 자격정보를 사용한다.
- NOLOGIN 함수 소유자, 고정 search_path, 열 제한 view, 좁은 변경 함수, PUBLIC 실행 권한 회수. runtime에는 소유권, BYPASSRLS, 역할 membership을 주지 않는다.
- 기존 `tripmoney.*` 직접 SQL은 권한 view/함수 계약으로 변경한다. role DSN만 교체하고 기존 raw table SQL을 남기지 않는다.
- 인증 모듈이 사용할 좁은 Auth/session DB 계약과 staff 등록은 0008에 포함한다. 실제 로그인 UX는 00B 범위다.
- 연결 직후 예상 프로젝트, 환경 식별자, current_user를 확인한다. 인증서 검증을 끄거나 광역 `DATABASE_URL`로 fallback하지 않는다.

운영 전환 순서: 운영 경로 차단 배포 검사 완료, 암호화 데모 덤프와 manifest 확보, quarantined 데이터 정리, 역할·자격정보 회전, 각 역할 직접 거부 검사. 덤프 최대 보관 기간은 14일이다. 이 문서는 해당 삭제·회전 작업을 실행하지 않는다.

## 5. Codex와 Claude의 역할

| 담당 | 작업 | 전달 자료 | 금지 사항 |
|---|---|---|---|
| Codex | 작업별 실패 테스트, 최소 구현, 타입·회귀·통합 검증, 증거 기록 | 명세, 작업 diff, 재현 명령 | 실제 고객 데이터, 비밀값, 운영 DSN을 출력하거나 AI 프롬프트에 넣지 않음 |
| Claude | 같은 기준 커밋의 읽기 전용 독립 검토, 우회 경로·누락된 테스트 지적 | 비식별 명세/diff/검증 요약 | Codex 작업 중 같은 파일 수정, 검토 중 운영 접속·배포·삭제 금지 |
| 창업자 | 사용자 승인, 외부 검토·구매, 운영 변경과 접수 활성화 | 처리된 검토 항목과 출시 증거 | 목업 시연이나 단위 테스트만으로 실접수 승인하지 않음 |

리뷰 체크포인트: 00A-1, 00A-2, 00B, 00C 각각 종료 시점. Claude가 로그인 만료로 검토할 수 없으면 검토 대기로 기록하고 다른 검증 작업만 이어간다. 독립 검토를 완료한 것으로 표시하지 않는다.

## 6. 일정과 외부 확인

기존 추정: 00A 18~24시간, 00B 18~24시간, 00C 10~16시간, 합계 46~64 엔지니어링 시간. 2026-08-28 코드 감사 기반 가정이며 현재 완료 약속이 아니다. 주당 18~21시간 배정 시 약 2.2~3.6주라는 이전 계산도 외부 대기시간을 제외한다.

일정 운영: 첫 주 목표는 00A-1 검증과 독립 검토다. 보안 의존성 처리와 DB 역할 전환의 실측 시간을 기록하고 00A-2 시작 전에 남은 시간을 재산정한다. 01~04는 00 출시 게이트와 각 하위 설계 승인 후 주차를 다시 잡는다. 기존 12주 표를 현재 날짜에 그대로 대입하지 않는다.
