제품 표면 목업 허브

네 표면과 열한 장면을 합성 데이터로 보여줍니다. 프로덕션 코드가 아닙니다. 설계 문서는 docs/superpowers/specs/2026-09-06-tripmoney-product-surfaces-ux-design.md입니다.

공개 랜딩

고객이 처음 보는 화면. 양쪽 기기 대응.

  • intake_on · 신청 폼 활성
  • intake_off · 접수 비활성 안내

총무 검토

총무가 초안을 승인하고 잠금을 요청하는 화면. 모바일 우선.

  • awaiting_organizer · 승인 대기
  • participant_review · 검토창 진행
  • finalized · 잠금 완료

참여자 공유

참여자가 본인 몫만 확인하고 결정하는 화면. 모바일 우선.

  • notice · 첫 고지
  • active · 본인 결과
  • expired · 만료 안내

운영자 워크벤치

직원이 케이스를 검수하고 잠그는 화면. 데스크톱 우선.

  • queue · 케이스 큐
  • case · 검수 중 상세
  • login · 로그인
